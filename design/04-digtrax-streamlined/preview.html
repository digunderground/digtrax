What to evaluate

  • Rows mode — single line per track, keyboard-driven. Compare information density to the current OneTagger Quick Tag rows. Anything missing? Anything redundant?
  • View toggle — does ROWS / CARDS in the toolbar feel right, or should this live in the sidebar / settings only?
  • Mono everywhere — V2 typography rules + V3 colors is the deliberate fusion. Does it read as power-tool credibility, or as "this is hard to read for 4 hours"?
  • UPPERCASE for display — track names, page titles, section headers. Some find this assertive; some find it shouty. Honest reaction welcome.
  • Bracketed primary actions — `[ SAVE 3 ]` style, only on the primary CTA. Light V2 motif, not full brutalism. Right balance?
  • DigTrax brand mark — DIG (white) + TRAX (cyan glow). Splits the wordplay naturally. Implementation note: this is design only — actual rename touches Cargo.toml, Info.plist, bundle ID, icons, repo. Plan as Phase 0.5 alongside universal builds.
